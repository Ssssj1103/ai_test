## 2. 手绘清单（画不全 = 还有洞）

纸上必须出现的模块与标注：

```
输入 "猫追老鼠" 
  → Tokenizer（BPE）→ token ID 序列
  → Embedding 查表 → (3, d) 向量
  → + 位置编码（RoPE/正弦）
  → [Transformer 层 × N]：
       多头自注意力（Q/K/V、√dk 缩放、因果掩码）→ 残差+LN → FFN → 残差+LN
  → 最终线性层 → 词表大小 logits
  → softmax → 下一个 token 概率 → 采样（T/top_p）→ 自回归循环
```

每个箭头旁边写一行"它解决了什么问题"（如位置编码旁写"Attention 不知道词序"）。
