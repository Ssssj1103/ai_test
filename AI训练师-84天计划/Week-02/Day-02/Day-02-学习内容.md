## 2. Self-Attention 六步流程（背下来）

以"猫 追 老鼠"3 个词为例（每个词用 4 维向量表示）：

```
第1步  X (3,4)          每个词一个输入向量
第2步  Q = X·Wq          查询矩阵：我在找什么（3,4）
       K = X·Wk          键矩阵：我有什么可被匹配（3,4）
       V = X·Wv          值矩阵：我实际携带的信息（3,4）
第3步  scores = Q·K^T    每个词对每个词打分（3,3）——就是 D1 的点积矩阵
第4步  scores /= √dk     缩放：除以 √dk，防止分数过大 → softmax 饱和 → 梯度消失
第5步  A = softmax(scores, 按行)   每行变成和为 1 的"关注度分布"
第6步  output = A·V      每个词的新表示 = 所有词信息按关注度加权平均（3,4）
```

**三个必答细节**：
- **为什么要 Q/K/V 三个矩阵**：让"我找什么 / 我提供什么匹配 / 我带什么信息"解耦——同一个词扮演三种角色，可学习的 Wq/Wk/Wv 让模型自己决定怎么匹配
- **为什么除以 √dk**：维度 dk 越大点积方差越大（方差 ≈ dk），大分数进 softmax 后趋近 one-hot，梯度接近 0。√dk 把方差拉回 ≈1
- **softmax 按行**：每一行是一个"查询词"对所有词的注意力分配，必须各自归一化

## 3. Multi-Head 一句话扩展

把上面整套流程用 h 组不同的 Wq/Wk/Wv 并行跑 h 次（如 8 头 × 32 维），拼接后过线性层融合——**每头用自己的视角看同一句话**。这就是 Transformer 图里那个"分又合"的结构。

残差 + LayerNorm（后置提及）：每层输出 = LayerNorm(x + 子层输出)——残差让梯度有"高速通道"，LayerNorm 稳定数值。知道作用即可，不用手推。

## 6. 与测试工作的类比（面试口语）

- Q/K/V 解耦 ≈ 测试中的三份材料：测试目标（Q）、被测系统接口文档（K）、实际系统行为（V）——**匹配（K）和取值（V）分离，才能"关注 A 的同时取 B 的信息"**
- √dk 缩放 ≈ 归一化测试指标量纲——不缩放的话分数大的项"一家独大"，掩盖其他信号
- 因果掩码 ≈ 回归测试不许"偷看未来的日志"——评测数据同理：**答案泄露进上下文 = 无效评测**（W6 评测集设计的红线）
