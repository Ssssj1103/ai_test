## 每日 3.5-4h 时间切法

| 时段 | 时长 | 内容 |
|---|---|---|
| 复盘 | 15' | 翻昨天的笔记，回答 3 个关键点 |
| 输入 | 60' | 读 `学习内容.md` + 指定资料 |
| 动手 | 60-90' | 跑/改 `dayXX_*.py`，必须产出文件 |
| 产出 | 45' | 填 `笔记模板.md` + 过 `验证.md` |
| 收尾 | 10' | 记录卡点，第二天优先解决 |

> **落后 2 天必须砍任务**：砍「输入」，不砍「动手」。只看不练 = 白学。
