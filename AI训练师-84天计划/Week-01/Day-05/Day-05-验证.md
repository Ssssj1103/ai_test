# 验证 · Day 05 · LLM 通识

## 一、自测题（口答）

1. 为什么不能用"每个汉字一个编号"这种最简单的方案做 LLM 词表？（至少 2 个理由）
2. 一段 1000 字的中文和 1000 词的英文，哪个 token 数更多？对 API 调用意味着什么？
3. 预训练和 SFT 的输入数据分别长什么样？"预测下一个 token"训练出来的模型为什么会"听懂指令"？
4. 偏好数据（chosen/rejected）和 SFT 数据（instruction/response）的本质区别？
5. 模型输出"根据我查到的资料……"但其实没联网——这算幻觉吗？属于哪个成因？

<details><summary>参考答案</summary>

1. ①序列太长：1000 字=1000 个 token，上下文窗口浪费严重；②词表照样处理不了英文等其他语言，且字与字的组合语义模型要自己学，训练效率低。BPE 用"高频合并"在序列长度和词表大小之间取得平衡。
2. 中文更多（常见 1 字≈1-2 token）。意味着：同样内容 API 计费更高、上下文窗口能装的内容更少、评测时要按 token 而不是字数预估成本。
3. 预训练输入是纯文本流（无标注），目标是预测下一个 token；SFT 输入是「指令→高质量回答」对。预训练模型本身只会"续写"，SFT 通过大量指令-回答对让它学会"看到问题给答案"的格式——本质是分布被微调到了"对话模式"。
4. SFT 是单条示范："遇到这类问题应该这样答"；偏好数据是同一问题的两个回答对比："这样答比那样好"——它教的是相对优劣（价值观），不是绝对内容。
5. 算幻觉（编造了不存在的引用行为）。主要属于"记忆混淆/过度自信"——模型在训练数据里见过这种"引用体"的格式，模仿了格式但没有真实来源。
</details>
