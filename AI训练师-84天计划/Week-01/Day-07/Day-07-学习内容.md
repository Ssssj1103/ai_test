## 2. GitHub 仓库设计（为什么这么摆）

```
ai-trainer-journey/          # 仓库名建议：真名拼音 + 关键词，好认
├── README.md                # 门面：我是谁/在学什么/3 个置顶作品（W8 后填充）
├── notes/                   # 每周笔记归档（week01-basics.md ...）
├── scripts/                 # 所有可运行脚本（day01_pandas_core.py ...）
├── datasets/                # 自建数据集（W4 的 SFT 数据集放这里）
├── reports/                 # 报告类产出（评测报告、质检报告）
└── flashcards/              # 面试卡片（llm-basics-v1.md ...）
```

**三条原则**：
1. **README 是简历**：招聘方只看 README 前 3 屏，第一周就把骨架搭好，之后只改内容
2. **每天一个绿点**：脚本已生成 git 提交命令，养成"当天产出当天 push"
3. **commit message 用英文动词开头**：`Add pandas stats script`——细节就是专业度

## 3. 《LLM 基础卡片》格式（后续每周追加）

```markdown
## Q: 为什么神经网络需要非线性激活函数？
**30 秒版**：没有非线性，多层线性变换可合并成一层，表达能力等价于线性模型，
学不出弯曲边界。实验：去掉 tanh 后圆圈分类准确率从 98% 掉到 50%。
**追问预备**：常见激活函数 tanh/ReLU/GELU 的区别？（W2 回答）
```

每条卡片 = 30 秒口语版 + 追问预备。**来源是你自己的实验数据**，不是抄书——这是和其他候选人的区别。
