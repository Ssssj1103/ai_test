## 2. 神经网络的三个构件（直觉版）

### 2.1 神经元 = 加权求和 + 非线性

```
输出 = activation(w1·x1 + w2·x2 + b)
```

- `w` 权重：每个输入的重要程度；`b` 偏置：整体调高调低的门槛
- **为什么必须非线性激活函数**：不加的话，多层叠加还是线性变换——叠 100 层等价于 1 层，永远画不出曲线边界。常用 `tanh`/`ReLU`/`sigmoid`
- 3B1B 类比：每个神经元是一个"投票器"，权重是"你说话的分量"

### 2.2 前向传播 = 数据流过网络得到预测

```
输入 X (N,2) → 隐藏层 [线性变换 → tanh] (N,8) → 输出层 [线性变换 → sigmoid] (N,1) → 概率 p
```

D2 的"y=wx+b"只有一步；神经网络就是把这一步**串多层**，中间层自动学出特征组合。

### 2.3 反向传播 = 链式法则把"错多少"传回每个参数

- 流向：loss → 输出层梯度 → 隐藏层梯度 → 每个参数的梯度
- 你**不需要手推公式**，只需要记住三句话：
  1. 输出层梯度 = （预测 - 真实）/ 样本数（和 D2 线性回归一模一样）
  2. 每往回传一层，就乘一次"该层的局部导数"
  3. 每个参数的更新 = 学习率 × 它的梯度（和 D2 完全相同）
- **PyTorch 的价值**：第 2 步"自动微分"帮你做了，你只写前向传播——这就是为什么深度学习工程师爱它

## 3. 今日任务：学会"圆圈分类"

数据：平面上 300 个点，**圆内=1，圆外=0**。直线（逻辑回归级别）永远分不开，必须靠隐藏层弯出一条环形边界。这是"为什么需要非线性"的活证据。

训练成功的标志：准确率从 50% 左右升到 **95%+**。

## 6. 与测试工作的类比（面试口语）

- 网络参数（W、b）≈ 被测系统的"内部状态"——你不用读懂每一行代码，但要看懂"输出随输入怎么变"
- 训练循环 ≈ 自动化回归：每轮"跑一次 → 量一下 → 调一点"
- 隐藏层神经元太多 ≈ 测试用例过度设计：训练集表现好、泛化差（呼应 D2 过拟合）
